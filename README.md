# SharePoint Search Toolkit Reference

A reference collection for investigating SharePoint search queries and exploring the PnP Modern Search web parts used to build search experiences.

| Component | What's included |
| --- | --- |
| [SharePoint Search Query Tool](SharePoint%20Search%20Quary%20tool/) | Packaged Windows executable and supporting assemblies. |
| [PnP Modern Search 4.12.2](pnp-modern-search-4.12.2/) | A source snapshot with search box, results, filters, and verticals web parts. |

## Start here

- For interactive query troubleshooting, use the [upstream SharePoint Search Query Tool](https://github.com/pnp/PnP-Tools) for its documentation and distribution information. This repository contains the packaged binary for reference.
- For web part configuration and deployment, start with the [included PnP README](pnp-modern-search-4.12.2/README.md) and the [PnP Modern Search documentation](https://microsoft-search.github.io/pnp-modern-search/).
- To explore the implementation, browse the [search web parts](pnp-modern-search-4.12.2/search-parts/src/webparts/) and [extensibility project](pnp-modern-search-4.12.2/search-extensibility/).

The bundled projects are upstream PnP work. The PnP Modern Search snapshot retains its [upstream license](pnp-modern-search-4.12.2/LICENSE).
